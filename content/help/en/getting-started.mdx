## Getting started

This FoodCost help article covers getting started inside the product.

### Steps

1. Open the matching module from the sidebar.
2. Use the contextual (?) tips on non-obvious fields.
3. Check the live cost panel before you save.

### Useful links

Try a one-off calc in the [food cost calculator](/en/calculator). For the full product, start the [trial](/en/pricing).

Still stuck? Open **Help → Contact support** in-app and include the page you are on.
